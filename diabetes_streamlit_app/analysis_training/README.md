# 🩺 Diabetes Project

This project is structured into two main Python files that handle different parts of the workflow:

- **analysis.py**  
  Contains the exploratory data analysis (EDA) process. This includes data cleaning, handling missing values, visualizations (age, BMI, prevalence, correlations), and deriving insights from the dataset.

- **ml.py**  
  Focuses on the machine learning pipeline. It covers data preprocessing, feature scaling, model training, evaluation, and saving the trained model for deployment.

Together, these scripts provide a full pipeline — from exploring the dataset to building and evaluating predictive models for diabetes risk.
