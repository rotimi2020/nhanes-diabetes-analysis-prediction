# app.py  

This file contains the full Streamlit application code for the diabetes project. It brings together both parts of the workflow:  

- **Visualization:** Interactive charts and plots that show trends such as age distribution, BMI by diabetes status, prevalence by gender/race, and feature correlations.  
- **Prediction:** A machine learning interface where users can input health parameters and get a diabetes risk prediction in real time.  

In short, `app.py` is the central script that powers the complete diabetes app, combining analysis and machine learning into one interactive tool.
