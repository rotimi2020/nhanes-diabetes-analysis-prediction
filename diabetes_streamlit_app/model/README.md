# Machine Learning Files for the Diabetes App  

These files are key for the prediction functionality of the app:  

- **diabetes_model.pkl** – The trained machine learning model used to predict diabetes risk.  
- **feature_names.pkl** – Stores the feature names required by the model for consistent input.  
- **scaler.pkl** – Contains the scaling parameters to standardize input data before prediction.  
- **model.py** – Script for building, training, and saving the ML model.  

📌 Together, they ensure the app can accurately process inputs and generate predictions.
